# Weddings by Harsha

> Luxury Wedding Planning & Event Management in Bengaluru and Mysuru.

Website built for **Weddings by Harsha**, featuring a modern royal crimson & champagne gold aesthetic, animated Gaja Vandana elephant crest on the landing screen, direct warehouse & godown inventory advantage, filterable portfolio lightbox, local SEO engine for 17 key corridors in Bengaluru & Mysuru, and direct WhatsApp integrations.

---

## 🌟 Key Highlights & Features

- **Royal Elephant Animated Crest**: Featured on the initial Launch Screen / Preloader where the elephants' trunks gracefully move up and down in a welcoming royal salute with golden confetti blessing effects on tap.
- **Brand Logo Integration**: Includes Harsha's official circular WH crest and royal elephant insignias.
- **Direct Godown Inventory**: Highlights the in-house warehouse in Kasthuriba Nagar / Azad Nagar, Bengaluru for stage fabrication, aluminum trussing, and acoustics.
- **Filterable Portfolio Gallery**: Responsive masonry layout with modal Lightbox for Mandaps, Royal Gardens, Traditional Pandals, Receptions, and Corporate events.
- **Areas We Serve (Dedicated Showcase)**: Single dedicated locality explorer view showcasing key corridors including **Banashankari (1st–4th Stage)**, **Vijayanagar**, **Basavangudi**, **Jayanagar**, **Rajajinagar**, **JP Nagar**, **Yeshwanthpur**, **Kengeri**, **Bommasandra**, **Electronic City**, and Mysuru Palaces.
- **Direct Lead Routing**: Automatic pre-filled WhatsApp lead dispatch to `+91 9108619752`.

## 🛠️ Tech Stack

- **Core**: Semantic HTML5, Vanilla CSS3 (Custom Design System tokens), Modern ES6 JavaScript
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Micro-Animations**: Canvas Shimmer Particles & Canvas Confetti

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
